# Wait_a_min

주제 : 웨이팅 번호표 어플리케이션

기능 : 실시간 대기 현황 시각화, 푸시 알림 & 자동 호출, AI 기반 예상 시간 계산, QR 코드/간편 인증, 시각/청각 장애인을 위한 음성 안내, 진동 알림 등

-화면구성-

화면디자인

화면 : 로그인화면, 메인화면, QR 찍는 화면, 회원가입 화면, 최근 히스토리

로그인화면 : 아이디, 비밀번호, 비밀번호 찾기, 아이디찾기, 회원가입, 로그인 버튼

메인화면 : 대기현황, 대기인원, 대기 시간, 대기열 등록버튼

하단바  : 메인페이지, 등록버튼, 히스토리 버튼, 마이페이지

등록화면 : 번호입력란, QR 인식란

히스토리 : 현재등록 가개, 이전에 등록한 가게 목록

혜현은 PRD 만들어 오도록
